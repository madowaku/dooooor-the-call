# itch.io page text (English)

## Title

DOOOOOR: THE CALL

## Short description (tagline)

Every door in the building has lost its knob. You carry one. Somewhere, a black telephone keeps ringing.

## Description

**DOOOOOR: THE CALL** is a short, quiet spatial puzzle from 2004 that nobody seems to have a record of.

You are standing in a dim corridor. A telephone is ringing somewhere inside the building, and it has been ringing since before you arrived. You try the nearest door. There is a hole where the knob should be.

There is a doorknob in your coat pocket.

- **One knob.** Push it into a door and the door is yours. Pull it out and take it with you; the door stays exactly where you left it.
- **Doors turn.** Each heavy leaf swings around a post and always plugs one doorway. Open one way and you close another.
- **One side only.** A door has a socket on one face. From the other side it is just a wall that happens to be made of wood.
- **You go with the door.** Push and you follow it in. Pull and you shut yourself out.
- **Listen.** The bell travels through open doorways, through a barred window, through a vent. A closed door muffles it. The loudest place is not always the place you can walk to from here.

Nothing chases you. Nothing jumps out. There is only the building, the bell, and the order in which you decide to close things.

When you answer, the ringing stops.

**Play time:** about 10 minutes.
**No text tutorial, no music.** Headphones recommended. An optional on-screen sound indicator (C key / Y button: off, normal, strong) shows the bell as ripples on the rim of the screen: where it comes from, how loud it is, and whether a closed door is muffling it. The game can be finished with the sound off.

## Controls

| | Keyboard | Gamepad |
|---|---|---|
| Move | Arrow keys / WASD | D-pad / left stick |
| Action (touch, attach knob, grab, let go, answer) | Z / Space / Enter | A |
| Take the knob out | X / Backspace | B |
| Sound indicator: off / normal / strong | C | Y |
| Pause | Esc | Start |
| Fullscreen | F11 / Alt+Enter | |

While holding a door, press toward one of the arrows on the floor to turn it.
